# 002 ASCII／CRT 終端機
catalog ID lemo-opuscar:ascii-crt，固定commit fdc46d7f0e20cc953a71d56241a92d1b4cb7298e。
候選：氣象記錄終端／水滴內嵌文字／開關機循環；選氣象記錄，依共用旁白六節點呈現海面→水氣→凝結→雲→雨→海面。
參考：單色琥珀終端的字符密度、掃描線、光暈；不複製示範故事、地球、角色、聲音或標誌。
全畫面繪製真實字符，使用原生term.js測量字形密度與glyph atlas，crt.js執行WebGL後處理；中文以同樣網格雙格字形補充。鏡頭只改字符格大小；主體以格位移；保留暗部與清楚輪廓。字幕放底部LOG輸出。
20秒1080×1920/30fps；時間節點沿用原SRT。逐字鍵入僅系統標題；旁白字幕完整顯示，因只有句子事件而沒有逐詞時間，不偽造逐詞同步。
旁白重用001真實068；混音只降低1dB保留峰值餘量。沒有付費API、沒有重配音。
本短測不做合成樂、機器聲變聲、逐詞ASR，列為來源完整藝術要求未執行。先驗證代表靜幀再渲染，另執行film_gate；不因科技風格自動豁免。
