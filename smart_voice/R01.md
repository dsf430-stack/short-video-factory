# R01 儒雅青年配音

R01 與原 068 並存。068 workflow、音色及參數不變；R01 使用官方
`scholarly-young-man` 參考和原版 VoxCPM2 MLX 配音適配器讀取本次新稿。

在 Actions 選「R01 儒雅青年配音」→ Run workflow → 填 narration 與 filename。
成功後下載 `r01-voice-output`，內含 MP3、WAV、實測 alignment 和聲音檢查紀錄。
這是按需執行的 Actions 入口，不是常駐 HTTP API；artifact 保存30天，隨時可再提交新稿。

官方程式固定 v1.4.1 / `3ae9b78d22af907afe70c1af4b8dc677f883bae1`，
MLX Audio 0.5.8，模型固定 `d52725898a0675703f7f9ddc5a4d1a3cdbb99032`。
模型約3.2GB，首次下載，之後嘗試重用 Actions cache。使用公開倉庫的標準
macos-14 Apple Silicon runner，不啟用付費大型 runner，不需要模型 API 金鑰。

若原版聲音門禁不通過，workflow 失敗並保留診斷，不交付參考音檔或切換聲線冒充。
新文字合成仍須以實際成功 run 和產出的 MP3 為驗證；單純提交 workflow 不算成功。
主觀音色、自然度與長稿品質應分開驗收。發布聲音時標示 AI 生成。
